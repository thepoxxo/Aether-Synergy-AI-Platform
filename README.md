# 🌟 Aether Synergy — AI 3D Design & Marketing Engine

> Plataforma SaaS de diseño 3D integrado con Inteligencia Artificial para **Moda Urbana / Streetwear**, **Decoración de Interiores** e **Instrumentalización & Audio Hardware**.

---

## 🚀 Características Principales

- 🧊 **Motor 3D Real (Three.js WebGL):** Soporte nativo para mallas `.GLB`, `.GLTF` y `.OBJ` con Drag & Drop, shaders Toon Cel-Shaded y PBR Realista.
- 📱 **Touch-Optimized para Tablets / iPads / PC:** Controles multitouch sin lag y barra lateral colapsable (Mini-Dock) para máxima área de trabajo.
- 🗣️ **Asistente IA con Voz Interactiva (Web Speech API):** Avatar flotante *Kai* con guía paso a paso y síntesis de voz en tiempo real.
- 🎬 **AdGen AI Video Marketing:** Conexión con *OpenAI Sora, Runway Gen-3, Kling AI, Luma Dream Machine*, movimientos de cámara cinemáticos y editor de línea de tiempo multipista.
- 🌐 **Global Suppliers B2B:** Directorio de fabricantes verificados en Portugal, Turquía, Colombia, Italia y Asia con cotizaciones de volumen y fichas técnicas Tech Pack.
- 📊 **Super Admin Suite:** Telemetría en tiempo real, desglose de costos operativos de APIs de IA y simulador interactivo de rentabilidad.
- 🔐 **Sistema de Autenticación & Roles RBAC:** Free Starter ($0), Pro Designer ($49), Agencia Enterprise ($149), Super Admin (Root) con verificación 2FA.
- 🌐 **Soporte Multilingüe (i18n):** 7 idiomas disponibles (🇪🇸 Español, 🇺🇸 Inglés, 🇯🇵 Japonés, 🇮🇹 Italiano, 🇫🇷 Francés, 🇨🇳 Chino, 🇩🇪 Alemán).

---

## 🛠️ Tecnologías Utilizadas

- **Frontend:** React 18 + TypeScript + Vite
- **3D Engine:** Three.js + WebGL 2.0
- **Estilos & UI:** Tailwind CSS + Lucide Icons + Canvas Confetti
- **Base de Datos & Tipos:** PostgreSQL / Supabase Schema (`schema.sql`)

---

## 📦 Instalación y Ejecución Local

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/TU_USUARIO/aether-synergy-design-ai.git
   cd aether-synergy-design-ai
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

4. **Compilar para producción:**
   ```bash
   npm run build
   ```
